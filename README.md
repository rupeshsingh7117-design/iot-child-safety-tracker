# Cloud-Connected IoT Child Safety & Live Location Tracking System

## Overview
This project presents a cloud-connected IoT solution for real-time child safety monitoring and location tracking. The system integrates GPS and GSM modules to provide live location updates and emergency SOS alerts.

## Objectives
- Track child location in real time
- Improve child safety through continuous monitoring
- Generate emergency SOS alerts during critical situations
- Enable remote access through a cloud-based platform

## Features
- GPS-based live location tracking
- GSM communication for data transmission
- Emergency SOS alert mechanism
- Cloud-connected monitoring dashboard
- Real-time location visualization

## System Architecture
The system consists of GPS and GSM modules connected to an IoT device that collects location information and transmits it to a cloud server. Users can access tracking data and alerts through a monitoring dashboard.

## Technologies Used
- IoT System Design
- GPS Module
- GSM Module
- Cloud Computing
- Embedded Systems
